# Objective physiological phenotyping: Sleep-EDF module

![Conceptual scientific cover](https://raw.githubusercontent.com/terry0809000/objective-physiological-phenotyping/main/assets/project-cover.png)

Sleep leaves a rich physiological record. I am interested in the patterns we can describe from it—and in the line between an objective pattern and a diagnosis that the data never measured.

This release contains the clean-room Sleep-EDF module: subject-grouped staging, night architecture, descriptive disruption phenotypes and uncertainty analyses. It does not measure subjective complaints or psychiatric diagnoses. NHANES and wearable modules are still being located and are not included or claimed as complete.

**Research direction:** AI for Health

## Methods and inputs

Sleep-EDF subject-grouped staging, night architecture and training-reference descriptive disruption phenotypes.

Public Sleep-EDF Expanded source archive, acquired separately. This saved implementation covers the clean-room sleep module of the multi-domain product; the NHANES and wearable module source mapping remains open.

## Scope

Sleep module only: NHANES/wearable source mapping remains open. Objective disruption does not measure subjective complaints or psychiatric diagnosis.

Existing source was organized for publication; scientific experiments and tests were not rerun. Cover art is conceptual and does not depict measured results.
