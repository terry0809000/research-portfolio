# Source-only clinical model selection under missingness stress

![Conceptual scientific cover](https://raw.githubusercontent.com/terry0809000/ehr-missingness-model-selection/main/assets/project-cover.png)

I wanted to know whether stress-testing missing observations would change which clinical model we choose. The source pilot gave a useful reason to stop: all seven selection rules chose the same candidate.

This repository keeps that finding visible alongside the extraction and selection code. Confirmation data stayed locked; external benefit was not established. A stopping rule is part of the research, and preserving it matters as much as preserving a promising result.

**Research direction:** Trustworthy AI

## Methods and inputs

Credentialed source extraction, missingness-stress pilot and explicit model-selection stopping rules.

Credentialed MIMIC-IV source inputs; source-only study with no claimed external benefit. No patient rows or fitted objects bundled.

## Scope

All seven source selection rules chose the same candidate; no external or source-confirmation benefit was established.

Existing source was organized for publication; scientific experiments and tests were not rerun. Cover art is conceptual and does not depict measured results.
