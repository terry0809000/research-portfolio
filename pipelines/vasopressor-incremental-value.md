# Incremental value of vasopressor prediction

![Conceptual scientific cover](https://raw.githubusercontent.com/terry0809000/vasopressor-incremental-value/main/assets/project-cover.png)

A treatment sequence contains more than a single dose. I wanted to understand whether disease-specific patterns of vasopressor use add information beyond the clinical picture already available at a fixed prediction landmark.

This code follows that question through ICU extraction, cross-fitted process encoders, baseline comparisons and robustness analyses. The saved analyses did not establish a stable external incremental advantage. The later hierarchy and tuning are documented as exploratory rather than presented as untouched confirmation.

**Research direction:** Prediction Modelling

## Methods and inputs

ICU extraction, disease-specific cross-fitted process encoders, baseline comparisons and robustness analysis.

Credentialed ICU archives. Raw records, predictions and fitted models are kept private.

## Scope

The later hierarchy and tuning are exploratory; a stable external incremental advantage was not established.

Existing source was organized for publication; scientific experiments and tests were not rerun. Cover art is conceptual and does not depict measured results.
